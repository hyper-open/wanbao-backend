# 万宝工具箱 微信提审合规对照清单（P0 配套）

> 用途：提交小程序审核与上线前的逐项核对。代码侧标识/举报/协议页已实现（见 design.md §16.3 C1），本清单覆盖**微信后台配置与法务动作**。
> 完成标准：每项勾选并注明日期/经办人。

## 1. 文书（docs/ 下模板）

- [ ] `docs/user-agreement.md`：经法务审阅；填写全部【占位符】（主体名称、生效日期、联系邮箱、模型服务商清单）
- [ ] `docs/privacy-policy.md`：经法务审阅；填写占位符；**确认附件自动删除天数（N≤30）与代码一致**
- [ ] 两份文书同步至小程序内页面 `pages/agreement`（占位符替换后）
- [ ] 文书在小程序后台"服务类目-用户协议"或"关于"入口可公开访问

## 2. 微信后台「用户隐私保护指引」（逐项对照隐私政策声明）

- [ ] 收集"微信 openid"（登录）——用途：建立与识别账户
- [ ] 收集"用户主动提交的文本/文档信息"——用途：完成 AI 处理任务
- [ ] 收集"订单信息"——用途：充值与对账
- [ ] 声明"上传文件"（wx.chooseMessageFile）——用途：解析附件
- [ ] 声明"向第三方提供"：已备案大模型服务商、对象存储（列明）
- [ ] 声明信息存储期限与删除方式（任务后 N 天自动删除 + 手动删除）
- [ ] 指引与小程序内实际收集行为**完全一致**（多收会被驳回，少收会被判违规）

## 3. 类目与资质

- [ ] 服务类目：工具类（个人主体可用类目，AI 生成相关如被要求补充材料按平台指引提交）
- [ ] 小程序认证 + ICP 备案状态确认（个人主体备案要求）
- [ ] 如平台要求"生成式 AI"相关资质/承诺函：按《生成式 AI 服务管理暂行办法》路径提供（我方为接入已备案模型方）

## 4. AI 生成内容标识（代码已实现，审核自验）

- [ ] 结果页可见声明："本内容由 AI 生成，仅供参考"（result 页）
- [ ] docx 导出：末尾说明行 + 元数据（author/category）——用 test_p0.py 验证
- [ ] pptx 导出：首页备注 + 元数据——用 test_p0.py 验证
- [ ] 小程序内提供投诉举报渠道（result 页"反馈/举报"）+ admin 后台处理记录可查

## 5. 内容安全

- [ ] `CONTENT_SECURITY_PROVIDER` 上线时切换/叠加真实审核（微信 msgSecCheck 或三方），mock 词表不可作为生产防线
- [ ] 输出审核开启（当前已接入 executor 出口）
- [ ] admin"反馈/用户"页有专人处理节奏（举报响应承诺 ≤15 个工作日，写入协议）

## 6. 支付合规

- [ ] 微信虚拟支付开通与商户信息确认（个人主体限额 10 万/月知悉）
- [ ] iOS 档位价格上浮对冲 12% 佣金确认
- [ ] 停售/预约逻辑演练（本月限额触顶路径，§16.2）
